# Ερωτηματολόγιο νέου πελάτη

Το ερωτηματολόγιο που στέλνετε στους πελάτες είναι το συμπληρώσιμο PDF
[`client-questionnaire.pdf`](client-questionnaire.pdf). Αλλαγές: επεξεργαστείτε το
`scripts/questionnaire/build.mjs` και τρέξτε `npm run questionnaire`. Η λίστα παρακάτω είναι η ίδια, για εσάς.

Μόνο όσα δεν μπορούμε να αποφασίσουμε εμείς. Όλα τα υπόλοιπα έχουν έτοιμη προεπιλογή
(δείτε στο τέλος) και ο πελάτης μπορεί να τα αλλάξει αργότερα από το admin.

## 1. Το κατάστημα
- [ ] Όνομα καταστήματος
- [ ] Χρώμα επωνυμίας (αν δεν έχει, διαλέγουμε εμείς)
- [ ] Domain (π.χ. `myshop.gr`): το έχει ήδη ή να το αγοράσουμε;
- Λογότυπο: το στέλνει με email στο **support@devroic.com**

## 2. Επικοινωνία
- [ ] Email και τηλέφωνο επικοινωνίας (φαίνονται στο κατάστημα)
- [ ] Email που θα λαμβάνει τις νέες παραγγελίες
- [ ] Email για τον λογαριασμό διαχείρισης (admin), με τον οποίο θα ανεβάζει προϊόντα

## 3. Αποστολές
- [ ] Τρόποι αποστολής και κόστος (π.χ. courier 3,50 €, παραλαβή από το κατάστημα δωρεάν)
- [ ] Δωρεάν αποστολή πάνω από κάποιο ποσό;

## 4. Πληρωμές
- [ ] Δέχεται και **αντικαταβολή**; Αν ναι, με επιπλέον χρέωση;

## 5. Στοιχεία για τη Stripe (πληρωμές με κάρτα)
- [ ] Μορφή επιχείρησης (ατομική / εταιρεία), επωνυμία, ΑΦΜ, διεύθυνση, τι πουλάει
- [ ] Υπεύθυνος: ονοματεπώνυμο, ημερομηνία γέννησης, κινητό, email
- [ ] Μόνο για εταιρείες: εταίροι με ποσοστό άνω του 25%
- [ ] IBAN και δικαιούχος (εκεί κατατίθενται οι πληρωμές)
- [ ] Όνομα στην κίνηση της κάρτας (έως 22 χαρακτήρες)
- Η επιβεβαίωση ταυτότητας γίνεται από τον ίδιο στον σύνδεσμο της Stripe, όχι με email.

Η επωνυμία, το ΑΦΜ και η διεύθυνση μπαίνουν και στους όρους χρήσης του καταστήματος.

## Προεπιλογές (δεν ρωτάμε, εκτός αν το φέρει ο πελάτης)

| Ρύθμιση | Προεπιλογή |
|---|---|
| Προϊόντα, κατηγορίες, φωτογραφίες | Τα ανεβάζει ο ίδιος ο πελάτης από το admin |
| Πληρωμή | Ηλεκτρονικά με κάρτα / Apple Pay / Google Pay (Stripe). Ο πελάτης ανοίγει λογαριασμό Stripe στο όνομα της επιχείρησης κατά το στήσιμο |
| Τραπεζική κατάθεση | Ανενεργή (ενεργοποιείται από το admin αν τη ζητήσει) |
| Γλώσσα / νόμισμα | Ελληνικά, EUR |
| Γραμματοσειρά, στρογγυλότητα | Inter, μοντέρνο στυλ |
| Σκοτεινό θέμα | Αυτόματα, ανάλογα με τη συσκευή του επισκέπτη |
| Αγορά χωρίς λογαριασμό | Ναι |
| Σύνδεση με Google | Ναι (δωρεάν, τη στήνουμε εμείς). Apple μόνο αν το ζητήσει (99 $/έτος) |
| Τιμές | Περιλαμβάνουν ΦΠΑ |
| Απόθεμα | Παρακολουθείται, τα εξαντλημένα φαίνονται ως «Εξαντλήθηκε» |
| Banner αρχικής, μπάρα ανακοινώσεων | Τα γράφουμε εμείς από το όνομα/τα προϊόντα |
| Όροι χρήσης, απόρρητο, επιστροφές | Πρότυπα κείμενα, όπου συμπληρώνουμε τα στοιχεία της επιχείρησης (14 ημέρες επιστροφή) |
| Social media, ωράριο, κουπόνια | Τα προσθέτει ο πελάτης από το admin όποτε θέλει |
