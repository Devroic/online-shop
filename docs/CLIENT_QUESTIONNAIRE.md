# Ερωτηματολόγιο νέου πελάτη

Στείλτε αυτή τη λίστα σε κάθε πελάτη **πριν** στήσετε το κατάστημά του. Οι απαντήσεις
μπαίνουν σχεδόν όλες στο `clients/<πελάτης>.json` (δείτε `clients/example.json`) ή
ρυθμίζονται αργότερα από τον ίδιο μέσα από το admin.

## 1. Ταυτότητα καταστήματος
- [ ] Όνομα καταστήματος (όπως θα φαίνεται στο site και στα email)
- [ ] Σλόγκαν / μια φράση που περιγράφει το κατάστημα
- [ ] Λογότυπο σε υψηλή ανάλυση (ιδανικά SVG ή PNG με διάφανο φόντο) και, αν υπάρχει, εικονίδιο (favicon)
- [ ] Χρώματα της επωνυμίας (κωδικοί HEX αν τους έχει, αλλιώς παραδείγματα που του αρέσουν)
- [ ] Γραμματοσειρά ή ύφος (μοντέρνο, κλασικό, παιχνιδιάρικο…)
- [ ] Σκοτεινό θέμα: αυτόματα ανάλογα με τη συσκευή του επισκέπτη (προτείνεται), πάντα φωτεινό ή πάντα σκοτεινό;
- [ ] Domain (π.χ. `myshop.gr`) — το έχει ήδη ή να το αγοράσουμε;
- [ ] Email από το οποίο θα στέλνονται τα email παραγγελιών (π.χ. `orders@myshop.gr`) (θα το επαληθεύσουμε στο Resend)

## 2. Νομικά & επιχειρηματικά στοιχεία
- [ ] Επωνυμία εταιρείας, ΑΦΜ, ΔΟΥ, ΓΕΜΗ, έδρα (απαιτούνται στους όρους χρήσης)
- [ ] Όροι χρήσης, πολιτική απορρήτου (GDPR), πολιτική επιστροφών — έχει δικά του κείμενα ή χρειάζεται πρότυπα;
- [ ] Οι τιμές περιλαμβάνουν ΦΠΑ; Ποιος συντελεστής;
- [ ] Χρειάζεται έκδοση τιμολογίου (στοιχεία τιμολόγησης στο checkout) ή μόνο απόδειξη;
- [ ] Συνδέεται με λογιστικό / ERP / παρόχο ηλεκτρονικής τιμολόγησης (myDATA);

## 3. Προϊόντα
- [ ] Λίστα προϊόντων (ιδανικά Excel): όνομα, περιγραφή, τιμή, τιμή πριν την έκπτωση, κωδικός (SKU), απόθεμα, κατηγορία
- [ ] Φωτογραφίες για κάθε προϊόν (τετράγωνες, φωτεινές, ίδιο φόντο αν γίνεται)
- [ ] Έχουν τα προϊόντα επιλογές (μέγεθος, χρώμα, άρωμα…); Αλλάζει η τιμή ανά επιλογή;
- [ ] Κατηγορίες και σειρά εμφάνισής τους
- [ ] Παρακολουθεί απόθεμα ή πουλάει κατά παραγγελία / χωρίς όριο;
- [ ] Να κρύβονται τα εξαντλημένα προϊόντα ή να φαίνονται ως «Εξαντλήθηκε»;
- [ ] Ψηφιακά προϊόντα / κάρτες δώρου;

## 4. Αποστολές
- [ ] Τρόποι αποστολής (courier, ΕΛΤΑ, δική του διανομή, παραλαβή από κατάστημα) και κόστος του καθενός
- [ ] Δωρεάν αποστολή πάνω από κάποιο ποσό;
- [ ] Σε ποιες περιοχές / χώρες στέλνει;
- [ ] Χρόνος αποστολής (π.χ. «1-3 εργάσιμες»)

## 5. Πληρωμές
- [ ] Αντικαταβολή; Με επιπλέον χρέωση;
- [ ] Τραπεζική κατάθεση; Στοιχεία λογαριασμού (τράπεζα, IBAN, δικαιούχος)
- [ ] Πληρωμή με κάρτα; (απαιτείται λογαριασμός Stripe στο όνομα της επιχείρησης)
- [ ] Ελάχιστο ποσό παραγγελίας;

## 6. Επικοινωνία & social
- [ ] Email, τηλέφωνο, διεύθυνση καταστήματος, ωράριο
- [ ] Facebook, Instagram, TikTok
- [ ] Σε ποιο email να έρχονται οι ειδοποιήσεις για νέες παραγγελίες;
- [ ] Ποιος/ποιοι θα έχουν πρόσβαση στη διαχείριση (email για λογαριασμούς admin)

## 7. Λογαριασμοί πελατών
- [ ] Να μπορούν οι πελάτες να συνδέονται με **Google**; (δωρεάν)
- [ ] Με **Apple**; (απαιτεί λογαριασμό Apple Developer, 99 $/έτος, στο όνομα της επιχείρησης)
- [ ] Αγορά χωρίς λογαριασμό (προτείνεται) ή μόνο με λογαριασμό;

## 8. Περιεχόμενο αρχικής σελίδας
- [ ] Κεντρικό μήνυμα (τίτλος + υπότιτλος) και φωτογραφία banner
- [ ] Μήνυμα για την μπάρα ανακοινώσεων (π.χ. «Δωρεάν αποστολή άνω των 50€»)
- [ ] Κείμενο «Σχετικά με εμάς»
- [ ] Ποια προϊόντα να προβάλλονται ως «Προτεινόμενα»
- [ ] Κωδικοί έκπτωσης για το λανσάρισμα;

## 9. Γλώσσα & αγορά
- [ ] Γλώσσα καταστήματος (Ελληνικά / Αγγλικά)
- [ ] Νόμισμα (EUR, …)

## 10. Τεχνικά / υπηρεσίες
- [ ] Google Analytics / Meta Pixel / Google Ads;
- [ ] Newsletter (Mailchimp κ.λπ.);
- [ ] Ποιος πληρώνει φιλοξενία, domain, email; (λογαριασμοί Supabase, Resend, Stripe στο όνομα της επιχείρησης)
- [ ] Υπάρχει παλιό site / κατάστημα από το οποίο πρέπει να μεταφερθούν δεδομένα ή URLs (redirects);
- [ ] Ημερομηνία που θέλει να «ανοίξει» το κατάστημα

---

## Λίστα παράδοσης (για εσάς)
Ακολουθήστε τον οδηγό [Νέος πελάτης](NEW_CLIENT.md): Supabase → Resend → Stripe → Vercel → domain →
`npm run configure` → έλεγχοι → backup.
