# Online Shop Template

Πλήρες, έτοιμο προς χρήση ηλεκτρονικό κατάστημα που προσαρμόζεται σε κάθε πελάτη
(όνομα, λογότυπο, χρώματα, γραμματοσειρά, προϊόντα, αποστολές, πληρωμές, σελίδες)
**χωρίς αλλαγές στον κώδικα**.

- **Frontend:** React 19 + Vite + React Router (κατάστημα και admin, το admin φορτώνει ξεχωριστά)
- **Backend:** Node.js + Express 5, SQLite (better-sqlite3), JWT σε httpOnly cookie
- **Πληρωμές:** αντικαταβολή, τραπεζική κατάθεση, κάρτα μέσω Stripe Checkout (προαιρετικά)
- **Email:** επιβεβαίωση παραγγελίας, ειδοποίηση admin, ενημέρωση κατάστασης, επαναφορά κωδικού (SMTP)
- **Γλώσσες:** Ελληνικά / Αγγλικά (ρύθμιση από το admin)

## Γρήγορη εκκίνηση

```bash
npm install
npm run seed      # demo προϊόντα + admin: admin@example.com / admin1234
npm run dev       # API στο :4000, κατάστημα στο http://localhost:5173
```

Διαχείριση: http://localhost:5173/admin

```bash
npm test          # tests του API
npm run build     # build του React app
```

## Λειτουργίες

**Πελάτες**
- Αρχική με banner, κατηγορίες, προτεινόμενα και νέα προϊόντα
- Κατάλογος με αναζήτηση (χωρίς τόνους, π.χ. «κουπα» βρίσκει «Κούπα»), κατηγορίες, φίλτρα, ταξινόμηση, σελίδες
- Σελίδα προϊόντος με gallery (swipe στο κινητό), επιλογές (μέγεθος/χρώμα) με δικό τους απόθεμα & τιμή, ένδειξη χαμηλού αποθέματος, σχετικά προϊόντα, «κολλητό» κουμπί αγοράς στο κινητό
- Καλάθι (πλαϊνό και σελίδα) που επανελέγχει τιμές/απόθεμα στον server, μπάρα «τόσα ευρώ ακόμα για δωρεάν αποστολή»
- Checkout σε μία σελίδα: αγορά χωρίς λογαριασμό, κουπόνια, τρόποι αποστολής, τρόποι πληρωμής, σχόλια, αποδοχή όρων
- Σελίδα παραγγελίας με χρονολόγιο κατάστασης και στοιχεία κατάθεσης, παρακολούθηση παραγγελίας με αριθμό + email
- Λογαριασμός: ιστορικό παραγγελιών, αποθηκευμένη διεύθυνση, αλλαγή/επαναφορά κωδικού. Οι παλιές παραγγελίες ως επισκέπτης συνδέονται αυτόματα με τον λογαριασμό
- Σελίδες περιεχομένου (όροι, απόρρητο, επιστροφές, σχετικά) και φόρμα επικοινωνίας

**Admin**
- Dashboard: έσοδα, παραγγελίες, μέση παραγγελία, γράφημα ημερών, δημοφιλέστερα, χαμηλό απόθεμα
- Παραγγελίες: φίλτρα, αναζήτηση, αλλαγή κατάστασης με ένα κλικ, αριθμός αποστολής, email στον πελάτη, εσωτερικές σημειώσεις, ιστορικό, εκτύπωση, εξαγωγή CSV. Η ακύρωση επιστρέφει το απόθεμα
- Προϊόντα: φωτογραφίες με drag & drop (αυτόματη σμίκρυνση σε WebP), επιλογές, τιμή προσφοράς, απόθεμα, γρήγορη αλλαγή αποθέματος από τη λίστα, αντίγραφο προϊόντος
- Κατηγορίες, κωδικοί έκπτωσης (%, ποσό, δωρεάν αποστολή, ελάχιστη παραγγελία, όριο χρήσεων, λήξη), τρόποι αποστολής (δωρεάν πάνω από ποσό, παραλαβή από κατάστημα), σελίδες, μηνύματα, πελάτες/διαχειριστές
- Ρυθμίσεις: όνομα, λογότυπο, favicon, χρώματα με ζωντανή προεπισκόπηση και έτοιμους συνδυασμούς, γραμματοσειρά, banner, μπάρα ανακοινώσεων, στοιχεία επικοινωνίας, social, πληρωμές, SEO

## Προσαρμογή για νέο πελάτη

1. Στείλτε στον πελάτη το [ερωτηματολόγιο](docs/CLIENT_QUESTIONNAIRE.md).
2. Φτιάξτε `clients/<πελάτης>.json` με βάση το [`clients/example.json`](clients/example.json)
   (ποσά σε **λεπτά**: `350` = 3,50 €).
3. Αντιγράψτε το `.env.example` σε `.env` και συμπληρώστε το.
4. Εφαρμόστε τη ρύθμιση:
   ```bash
   npm run configure -- clients/<πελάτης>.json
   ```
5. Τα προϊόντα ανεβαίνουν από το admin. Όλα τα υπόλοιπα αλλάζουν κι αυτά από το admin, οπότε ο πελάτης μπορεί να τα διαχειρίζεται μόνος του.

Κάθε πελάτης έχει **δικό του αντίγραφο** (δικό του server/container και φάκελο `data/`).
Ο κώδικας μένει κοινός: διορθώσεις στο template περνάνε σε όλους με `git pull` και επανεκκίνηση.
Οι αλλαγές στη βάση γίνονται με migrations (`server/src/db.js`) που εφαρμόζονται αυτόματα.

## Παραγωγή (production)

Ένα μόνο process σερβίρει το API και το React app.

**Με Docker**
```bash
cp .env.example .env   # PUBLIC_URL, JWT_SECRET, ADMIN_EMAIL/ADMIN_PASSWORD, SMTP…
docker compose up -d --build
docker compose exec shop node server/src/scripts/configure.js clients/<πελάτης>.json
```
Βάλτε μπροστά έναν reverse proxy με HTTPS (Caddy, Nginx, Traefik) που προωθεί στο `:4000`.

**Χωρίς Docker** (VPS με Node 20+)
```bash
npm ci && npm run build
NODE_ENV=production node server/src/index.js   # π.χ. μέσω pm2 ή systemd
```

**Backup:** ό,τι χρειάζεται βρίσκεται στον φάκελο `data/` (`shop.db` + `uploads/`).
Για ασφαλές backup ενώ τρέχει: `sqlite3 data/shop.db ".backup backup.db"`.

### Πληρωμές με κάρτα (Stripe)
1. Ο πελάτης ανοίγει λογαριασμό Stripe στο όνομα της επιχείρησης.
2. `STRIPE_SECRET_KEY` στο `.env`.
3. Webhook στο Stripe Dashboard → `https://<domain>/api/stripe/webhook` με events
   `checkout.session.completed`, `checkout.session.async_payment_succeeded`, `checkout.session.expired`,
   και το signing secret στο `STRIPE_WEBHOOK_SECRET`.
4. Ενεργοποίηση «Πιστωτική / χρεωστική κάρτα» στο admin → Ρυθμίσεις → Πληρωμές.

Οι παραγγελίες με κάρτα επιβεβαιώνονται μόνο όταν το Stripe ειδοποιήσει ότι πληρώθηκαν
(και ως εφεδρεία όταν ο πελάτης επιστρέψει στη σελίδα της παραγγελίας). Αν η πληρωμή
δεν ολοκληρωθεί μέσα σε 1 ώρα, η παραγγελία ακυρώνεται και το απόθεμα επιστρέφει.

## Ασφάλεια
- Οι τιμές, οι εκπτώσεις και το απόθεμα υπολογίζονται πάντα στον server, μέσα σε transaction
- Κωδικοί με bcrypt, session σε httpOnly cookie, rate limiting σε σύνδεση/checkout/επικοινωνία
- Helmet + Content Security Policy, έλεγχος όλων των εισόδων με zod
- Οι σελίδες παραγγελιών επισκεπτών ανοίγουν μόνο με μυστικό σύνδεσμο

## Δομή

```

  app.js, index.js         Express app, εκκίνηση
  db.js                    SQLite + migrations
  settings.js              ρυθμίσεις καταστήματος (προεπιλογές + αποθηκευμένες)
  services/                catalog, orders (τιμολόγηση/απόθεμα), payments (Stripe)
  routes/                  public, auth, orders, admin, stripe
  scripts/                 seed, configure, create-admin, bootstrap
client/src/
  pages/                   σελίδες καταστήματος
  admin/                   admin panel
  components/, context/    κοινά components, καλάθι, λογαριασμός, θέμα
  lib/locales/el.js        ελληνικές μεταφράσεις
clients/                   ρυθμίσεις ανά πελάτη
docs/                      ερωτηματολόγιο πελάτη
```
